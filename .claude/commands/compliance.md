# compliance

Check selected curriculum evidence requirements and local policies.

Run from the repository root:

```sh
npm run curriculum -- compliance
```

Read docs/compliance.md. Distinguish the NZ-only learning-hours check from institution policies. A clean result is not accreditation. Present rule codes with the records to fix.

Accepted flags: --version, plus --json. Dates use YYYY-MM-DD. Resolve ambiguous matches by listing the candidates and getting an exact id. Report the records returned, and say when none match.
