# edit-version

Amend a draft version, dates, credits or rationale.

Run from the repository root:

```sh
npm run curriculum -- edit-version --version=NEW/v1 --rationale="Employer panel feedback incorporated" --actor="Casey"
```

Read the relevant records first. Use the operator's actual dates and evidence. The example is illustrative, not an instruction to create records.

Accepted flags: --version, --title, --level, --credits, --review-due, --effective, --rationale, --actor, plus --json. Dates use YYYY-MM-DD. Resolve ambiguous matches by listing the candidates and getting an exact id. Record the instructed actor and report the saved record. Do not invent evidence or approvals.
