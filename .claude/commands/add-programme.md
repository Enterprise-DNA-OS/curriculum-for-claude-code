# add-programme

Register a programme and its owner.

Run from the repository root:

```sh
npm run curriculum -- add-programme --code=NEW --title="New Programme" --owner="Aroha" --jurisdiction=NZ --actor="Casey"
```

Read the relevant records first. Use the operator's actual dates and evidence. The example is illustrative, not an instruction to create records.

Accepted flags: --code, --title, --owner, --jurisdiction, --actor, plus --json. Dates use YYYY-MM-DD. Resolve ambiguous matches by listing the candidates and getting an exact id. Record the instructed actor and report the saved record. Do not invent evidence or approvals.
