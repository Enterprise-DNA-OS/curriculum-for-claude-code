# edit-module

Amend a draft module descriptor.

Run from the repository root:

```sh
npm run curriculum -- edit-module --version=NEW/v1 --module=NEW101 --hours=150 --actor="Casey"
```

Read the relevant records first. Use the operator's actual dates and evidence. The example is illustrative, not an instruction to create records.

Accepted flags: --version, --module, --title, --level, --credits, --hours, --aim, --content, --delivery, --actor, plus --json. Dates use YYYY-MM-DD. Resolve ambiguous matches by listing the candidates and getting an exact id. Record the instructed actor and report the saved record. Do not invent evidence or approvals.
