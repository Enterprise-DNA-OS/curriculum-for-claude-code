# documents

Read the requested version and run npm run docs for programme-specification, mapping-matrix or committee-pack. Select a version by its id prefix if necessary. Read the generated HTML and check programme title, version, state, coverage and decision evidence. These are working records, not issued qualifications or regulatory approvals. Keep files private and hand them over in chat.
