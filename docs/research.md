# Target selection and evidence

Checked 3 November 2026. Family: curriculum governance. Product: Curriculum for Claude Code. This family holds programme design, version review and outcome alignment, distinct from the registry's student administration, workforce training and student-success builds.

## Annual bill and uncertainty

The supplier-authored [UK G-Cloud 14 listing](https://www.applytosupply.digitalmarketplace.service.gov.uk/g-cloud/services/392409189737101) was returned by search with GBP 22,500 per licence per year. Direct HTTP retrieval returned 404 during this run. Treat that as a historical procurement benchmark, not a current quote, an actual paid invoice or an ANZ price. The [vendor website](https://akarisoftware.com/) leads to a demo request and has no numeric price on the pages reviewed. The landing page therefore uses no numerical price.

The vendor's [2024 service definition](https://assets.applytosupply.digitalmarketplace.service.gov.uk/g-cloud-14/documents/709676/392409189737101-service-definition-document-2024-05-07-0934.pdf) documents curriculum, review and catalogue capabilities, with optional modules and services. [Akari's client page](https://akarisoftware.com/clients/) confirms New Zealand and Australian institutions. No confirmed Akari purchaser was found in local customer/CRM context searched; live CRM was not consulted and no live customer claim is made. Larger institutional buyers are a weaker fit than Omni's usual owner-led business, so buyer fit scores only two.

## Export evidence

The Akari supplier listing describes configurable CSV report exports and JSON API output. It does not publish a universal CSV header set. The importer implements a documented, mapped joined report; the supplied fixture is synthetic. An actual institution must export the selected fields, map them and reconcile completeness. No authenticated Akari account was used. No one-click menu or full-account migration promise is invented.

## Rebuild scope

The implementation owns compulsory programme pathways, outcomes, assessments, mappings, review tasks and internal decisions. It has no student records, course delivery, proprietary curriculum catalogue, accreditation service, online publication or external system connection. Those limits prevent a claim that the entire incumbent suite was recreated.
